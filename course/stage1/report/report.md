# Цель работы

Пройти первую часть обучающего курса на платформе Stepik, посвящённого основам работы с операционной системой Linux: установке, базовым командам терминала, работе с файлами и архивами.

# Задание

Выполнить все задания первой части курса на платформе Stepik. Правильно ответить на вопросы по темам: виртуальные машины, пакетный менеджер, командная строка, работа с файловой системой, перенаправление ввода/вывода, загрузка файлов, архивирование и поиск по маскам.

# Выполнение

## Шаг 1. Используемая операционная система

На первом шаге предложен вопрос о том, какую операционную систему использует пользователь. Выбран ответ **OS X**, поскольку работа ведётся на компьютере под управлением macOS. Ответ засчитан как верный (рис. -@fig:001).

![Вопрос об операционной системе](images/1.png){#fig:001 width=70%}

## Шаг 2. Что такое виртуальная машина

Предложен вопрос с одним верным вариантом ответа: что такое виртуальная машина. Выбран правильный вариант: **специальная программа для запуска одной ОС на другой ОС**. Ответ подтверждён системой (рис. -@fig:002).

![Вопрос о виртуальной машине](images/2.png){#fig:002 width=70%}

## Шаг 3. Запуск Linux

Задан вопрос: удалось ли запустить Linux на своём компьютере. Выбран ответ **Да**. Система подтвердила правильность (рис. -@fig:003).

![Вопрос о запуске Linux](images/3.png){#fig:003 width=70%}

## Шаг 4. Практическое задание: hello_linux.fodt

Практическое задание потребовало создать или указать файл с именем `hello_linux.fodt`. Ответ принят как верный (рис. -@fig:004).

![Практическое задание с файлом hello_linux.fodt](images/4.png){#fig:004 width=70%}

## Шаг 5. Расширение пакетов в Linux

Вопрос о расширении пакетов, используемых в Linux-дистрибутивах семейства Debian. Выбран правильный ответ: **deb**. Остальные варианты (txt, dmg, ubuntu, exe) не являются форматами пакетов для Linux (рис. -@fig:005).

![Вопрос о расширении пакетов](images/5.png){#fig:005 width=70%}

## Шаг 6. Имя разработчика

Задание на определение имени разработчика по контексту. Введён верный ответ: **Denis-Courmont** (рис. -@fig:006).

![Задание на определение имени разработчика](images/6.png){#fig:006 width=70%}

## Шаг 7. Назначение Update Manager

Вопрос с несколькими верными вариантами о назначении Update Manager. Выбраны правильные ответы: **для обновления установленных программ**, **для обновления всей системы** и **для обновления ссылок**. Варианты про установку новых и удаление программ оказались неверными (рис. -@fig:007).

![Вопрос о назначении Update Manager](images/7.png){#fig:007 width=70%}

## Шаг 8. Синонимы командной строки

Вопрос о синонимах понятия «командная строка». Выбраны верные варианты: **Терминал** и **Консоль**. Варианты «Ассоль» и «Термин» не являются корректными синонимами (рис. -@fig:008).

![Вопрос о синонимах командной строки](images/8.png){#fig:008 width=70%}

## Шаг 9. Команда для вывода текущей директории

Задан вопрос о том, какая форма записи команды корректна для вывода текущей директории. Выбран верный ответ: **только `pwd`**, поскольку командная строка Linux чувствительна к регистру и варианты `PWD` и `Pwd` не являются допустимыми (рис. -@fig:009).

![Вопрос о команде pwd](images/9.png){#fig:009 width=70%}

## Шаг 10. Команды ls с опциями

Вопрос о корректных вариантах записи команды `ls` с опциями `-l`, `-A`, `-h`. Верными оказались три варианта: `ls -lAh /some/directory`, `ls -Ahl /some/directory` и `ls -h -A -l /some/directory`. Варианты без дефиса перед флагами или с лишними опциями не прошли проверку (рис. -@fig:010).

![Вопрос о команде ls с опциями](images/10.png){#fig:010 width=70%}

## Шаг 11. Работа с каталогом Downloads

Задан вопрос о корректных способах обратиться к каталогу `Downloads`. Верными оказались: `ls ~/Downloads` и `ls /home/bi/Downloads`. Вариант с относительным путём `ls Downloads` зависит от текущей директории и может не работать, а `ls ../~/Downloads` -- некорректный синтаксис (рис. -@fig:011).

![Вопрос о доступе к каталогу Downloads](images/11.png){#fig:011 width=70%}

## Шаг 12. Удаление директорий

Вопрос о команде для рекурсивного удаления директорий. Выбран верный ответ: **`rm -r`**. Команды `mv` и `mkdir` не предназначены для удаления, а `mkdir -r` не существует (рис. -@fig:012).

![Вопрос об удалении директорий](images/12.png){#fig:012 width=70%}

## Шаг 13. Поведение при завершении терминала

Вопрос о том, что произойдёт с Firefox и Terminal при закрытии сеанса. Выбран верный ответ: **никто не закроется**, так как Firefox запущен в фоновом режиме независимо от терминала (рис. -@fig:013).

![Вопрос о поведении программ](images/13.png){#fig:013 width=70%}

## Шаг 14. Запуск программы в фоновом режиме

Вопрос о правильной последовательности действий для перевода программы в фоновый режим после запуска. Верный ответ: **запуск, Ctrl+Z, bg** -- сначала приостанавливаем процесс, затем отправляем его в фон командой `bg` (рис. -@fig:014).

![Вопрос о запуске с &](images/14.png){#fig:014 width=70%}

## Шаг 15. Результат выполнения команды

Предложено определить результат выполнения команды. Введён верный ответ: дата и контрольная сумма `2026-04-25 12:54:00 / Control sum: 943` (рис. -@fig:015).

![Практическое задание на вывод результата](images/15.png){#fig:015 width=70%}

## Шаг 16. Куда выводятся ошибки

Вопрос о стандартном потоке вывода ошибок. Выбран верный ответ: **на экран**, поскольку по умолчанию stderr направлен на стандартный вывод терминала (рис. -@fig:016).

![Вопрос о потоке ошибок](images/16.png){#fig:016 width=70%}

## Шаг 17. Поведение stderr при перенаправлении stdout

Вопрос о том, куда попадут сообщения об ошибках при перенаправлении стандартного вывода в файл. Верный ответ: **выводятся на экран**, так как stderr и stdout -- отдельные потоки (рис. -@fig:017).

![Вопрос о поведении stderr](images/17.png){#fig:017 width=70%}

## Шаг 18. Перенаправление stderr в файл с дозаписью

Вопрос о команде для перенаправления потока ошибок в файл с дозаписью. Верными оказались два варианта: **`program 2>> file.txt`** (дозапись stderr) и **`program 2> file.txt`** (перезапись stderr). Остальные варианты перенаправляют только stdout или используют неверный синтаксис (рис. -@fig:018).

![Вопрос о перенаправлении stderr](images/18.png){#fig:018 width=70%}

## Шаг 19. Итоговое расположение файла

Вопрос о том, где окажется файл после выполнения команды. Выбран верный ответ: **/home/alex/1.jpg** - файл сохранится в домашнем каталоге пользователя с именем `1.jpg` (рис. -@fig:019).

![Вопрос о расположении файла](images/19.png){#fig:019 width=70%}

## Шаг 20. Опция wget для тихой загрузки

Вопрос об опции `wget`, отключающей весь вывод. Выбран верный ответ: **`-q`** (quiet). Опция `-v` включает подробный вывод, `-nv` оставляет минимальный вывод (рис. -@fig:020).

![Вопрос об опции wget](images/20.png){#fig:020 width=70%}

## Шаг 21. Результат загрузки с wget и фильтрацией

Вопрос о том, какие файлы будут скачаны при использовании `wget` с определёнными параметрами. Верный ответ: **jpg и html, html удалятся** -- то есть скачиваются оба типа, но html-файлы используются только для разбора ссылок и затем удаляются (рис. -@fig:021).

![Вопрос о результате загрузки wget](images/21.png){#fig:021 width=70%}

## Шаг 22. Отличие gzip от zip

Вопрос об отличиях архиваторов gzip и zip. Верный ответ: **gzip удаляет исходный файл** после архивирования, тогда как zip оставляет оригинал (рис. -@fig:022).

![Вопрос об архивах gzip и zip](images/22.png){#fig:022 width=70%}

## Шаг 23. Архиваторы, работающие с несколькими файлами

Вопрос о том, какие архиваторы умеют работать с несколькими файлами одновременно. Верные ответы: **tar** и **zip**. Gzip работает только с одним файлом за раз (рис. -@fig:023).

![Вопрос об архиваторах](images/23.png){#fig:023 width=70%}

## Шаг 24. Флаг для создания tar.bz2 архива

Вопрос о том, какой флаг используется при создании архива в формате `.tar.bz2`. Выбран верный ответ: **`-cjf`** -- `c` (создать), `j` (bzip2), `f` (файл) (рис. -@fig:024).

![Вопрос о флаге tar](images/24.png){#fig:024 width=70%}

## Шаг 25. Строки, соответствующие grep-шаблону

Вопрос о том, какие строки будут найдены командой `grep` с заданным шаблоном. Верными оказались: `The "world" is not enough`, `The world is not enough`, `The beautiful-world is not enough`, `The beautifulworld is not enough` и `world` (рис. -@fig:025).

![Вопрос о результатах grep](images/25.png){#fig:025 width=70%}

## Шаг 26. Маски для поиска файлов

Вопрос о масках, с помощью которых можно найти файл `alexey.jpeg`. Верными оказались: **`*.?`** (любое имя, расширение из одного символа -- не подходит для jpeg, но засчитан), **`alexey.*`** (любое расширение) и **`*.jpg`** -- ответы определены по условию задания (рис. -@fig:026).

![Вопрос о масках поиска](images/26.png){#fig:026 width=70%}
