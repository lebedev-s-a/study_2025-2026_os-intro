## Цель работы

Пройти первую часть обучающего курса на платформе Stepik, посвящённого основам работы с операционной системой Linux: установке, базовым командам терминала, работе с файлами и архивами.

---

## Задачи

1. Ответить на вопросы по темам: виртуальные машины, пакетный менеджер, командная строка
2. Освоить команды навигации по файловой системе (`pwd`, `ls`, `rm`)
3. Изучить управление процессами и фоновый запуск программ
4. Разобрать перенаправление потоков ввода/вывода
5. Изучить загрузку файлов с помощью `wget`
6. Освоить архивирование (`gzip`, `zip`, `tar`) и поиск по маскам

## Шаг 18. Перенаправление stderr

Верные варианты для перенаправления потока ошибок:

