## Цель работы

Пройти вторую часть обучающего курса на платформе Stepik, посвящённой работе с удалённым сервером: подключению по SSH, обмену файлами, запуску приложений в терминале, управлению процессами, многопоточным вычислениям и менеджеру терминалов tmux.

---

## Задачи

1. Изучить применение удалённого сервера и работу с SSH-ключами
2. Освоить копирование файлов командой `scp` и работу с FileZilla
3. Научиться устанавливать пакеты через `apt-get` и получать справку по программам
4. Запустить биоинформатические приложения FastQC и ClustalW
5. Освоить управление процессами: `jobs`, `ps`, `top`, `kill`, `fg`, `bg`
6. Разобрать многопоточность на примере `bowtie2`
7. Освоить менеджер терминалов `tmux`: вкладки, разделение экрана, сохранение сессий

## Шаг 2. SSH-ключи

Программа `ssh-keygen` создаёт два ключа: `id_rsa` и `id_rsa.pub`.

Верный ответ: **`id_rsa.pub`** - публичный ключ предназначен для открытого распространения и может быть передан кому угодно. Приватный ключ `id_rsa` хранится только локально и никогда не передаётся.

![Вопрос об SSH-ключах](images/2.png)

## Шаг 3. Копирование папки командой scp

Вопрос о команде для рекурсивного копирования папки `stepic` со всем содержимым на сервер.

Верный ответ:

```bash
scp -r stepic username@server:~/
```

Флаг `-r` обеспечивает рекурсивное копирование каталога вместе с подпапками и файлами.

![Вопрос о команде scp](images/3.png)

## Шаг 4. Устранение проблемы с apt-get

Если `sudo apt-get install program` не находит пакет, верные действия:

- **`sudo apt-get update`** - обновляет список доступных пакетов из репозиториев ✔
- **Проверка интернет-соединения** - без сети загрузка пакета невозможна ✔

Опция `--only-upgrade` работает только для уже установленных пакетов. Очистка диска не влияет на поиск пакета.

![Вопрос об устранении проблемы с apt-get](images/4.png)

## Шаг 5. Возможности программы FileZilla

FileZilla - графический FTP/SFTP-клиент для обмена файлами с сервером. Верные варианты:

- Просмотр содержимого директорий на своём компьютере ✔
- Копирование файлов со своего компьютера на сервер ✔
- Просмотр содержимого директорий на сервере ✔

Установка и запуск программ на сервере через FileZilla невозможны.

- **Настроить сервер для поддержки вывода на экран** (X11 forwarding через `ssh -X`) ✔
- **Проверить наличие терминальной версии программы** ✔

Запустить программу локально - не является ответом на вопрос о работе с сервером.

## Шаг 16. Состояние процессов после серии команд

Запущены `program1`, `program2`, `program3` в фоне. Затем выполнены действия:

```

Ctrl+C   -> program1 завершена
fg %2    -> program2 вышла на передний план

jobs     -> ?
```

Верный ответ: **только `program2` и `program3`** - первая завершена, вторая приостановлена, третья работает в фоне.

|---------|---------------|

Верный ответ: **одинаковые только у `ps` и `top`** - обе работают с PID процесса.

## Шаг 18. Мгновенное завершение процесса

Вопрос о команде для немедленного завершения остановленного процесса.

Верный ответ: **`kill -9`** - отправляет сигнал SIGKILL, который нельзя игнорировать. Команда `kill` без опций отправляет SIGTERM - приостановленный процесс его не обработает до возобновления.

```bash
kill -9 <PID>
```

![Вопрос о команде kill -9](images/18.png)

## Шаг 19. Поведение kill без опций на приостановленный процесс

Если процесс приостановлен через `Ctrl+Z`, а затем выполнена команда `kill` без опций:

Верный ответ: **процесс приступит к завершению, как только будет продолжён** - сигнал SIGTERM поставлен в очередь, но обрабатывается только при возобновлении процесса.

![Вопрос о поведении kill на приостановленный процесс](images/19.png)

Верный ответ: **столько, сколько оно потребляло в момент остановки** - при приостановке процесса его данные остаются в памяти, она не освобождается.

## Шаг 22. Завершение отдельного потока

Вопрос о возможности принудительно завершить один из потоков многопоточного приложения.

Верный ответ: **никак** - стандартные средства Linux (`kill`, `Ctrl+C`) воздействуют на весь процесс целиком. Адресно завершить отдельный поток снаружи невозможно.
