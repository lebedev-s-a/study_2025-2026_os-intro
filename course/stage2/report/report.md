# Цель работы

Пройти вторую часть обучающего курса на платформе Stepik, посвящённой работе с удалённым сервером: подключению по SSH, обмену файлами, запуску приложений в терминале, управлению процессами, многопоточным вычислениям и менеджеру терминалов tmux.

# Задание

Выполнить все задания второй части курса на платформе Stepik. Правильно ответить на вопросы по темам: SSH-ключи, команда `scp`, пакетный менеджер `apt-get`, программа FileZilla, запуск приложений в терминале, справочная система, управление процессами (`jobs`, `ps`, `top`, `kill`), многопоточность (`bowtie2`), менеджер терминалов `tmux`.

## Раздел 2.2. Обмен файлами

### Шаг 3. Копирование папки на сервер командой scp

Вопрос о команде для рекурсивного копирования папки `stepic` со всем содержимым на сервер. Выбран верный ответ: **`scp -r stepic username@server:~/`**. Флаг `-r` обеспечивает рекурсивное копирование (рис. -@fig:003).

![Вопрос о команде scp](images/3.png){#fig:003 width=70%}

### Шаг 4. Устранение проблемы с apt-get install

Вопрос о действиях, если `sudo apt-get install program` не находит пакет. Верные ответы: **`sudo apt-get update`** и **проверка интернет-соединения**. Опция `--only-upgrade` и очистка диска в данном случае не помогут (рис. -@fig:004).

![Вопрос об устранении проблемы с apt-get](images/4.png){#fig:004 width=70%}

Выбраны три верных варианта: **просмотр содержимого директорий на своём компьютере**, **копирование файлов со своего компьютера на сервер** и **просмотр содержимого директорий на сервере**. Установка и запуск программ на сервере через FileZilla невозможны (рис. -@fig:005).

## Раздел 2.4. Контроль запускаемых программ

### Шаг 16. Состояние процессов после серии команд

Вопрос: какие процессы покажет `jobs` после `fg %1`, `Ctrl+C`, `fg %2`, `Ctrl+Z`. Верный ответ: **только `program2` и `program3`**. `program1` завершён через `Ctrl+C`, `program2` приостановлен, `program3` работает в фоне (рис. -@fig:016).

![Вопрос о состоянии процессов](images/16.png){#fig:016 width=70%}

### Шаг 17. Идентификаторы в jobs, top и ps

Вопрос об идентификаторах процессов в `jobs`, `top` и `ps`. Выбран верный ответ: **одинаковые только у `ps` и `top`**, так как оба работают с PID. Утилита `jobs` использует собственные порядковые номера задач (рис. -@fig:017).

![Вопрос об идентификаторах процессов](images/17.png){#fig:017 width=70%}

### Шаг 18. Мгновенное завершение процесса

Вопрос о команде для мгновенного завершения остановленного процесса. Выбран верный ответ: **`kill -9`** (сигнал SIGKILL). Команда `kill` без опций отправляет SIGTERM, который приостановленный процесс игнорирует (рис. -@fig:018).

![Вопрос о команде kill -9](images/18.png){#fig:018 width=70%}

### Шаг 19. Поведение kill без опций на приостановленный процесс

Вопрос о том, что произойдёт при `kill` без опций к процессу, остановленному через `Ctrl+Z`. Выбран верный ответ: **процесс приступит к завершению, как только будет продолжен** (рис. -@fig:019).

![Вопрос о поведении kill на приостановленный процесс](images/19.png){#fig:019 width=70%}

# Выводы

В ходе прохождения второй части курса на платформе Stepik освоены следующие темы: работа с удалённым сервером по SSH, использование публичных ключей, копирование файлов командой `scp`, обмен файлами через FileZilla, управление пакетами через `apt-get`. Изучен запуск биоинформатических приложений: FastQC для контроля качества последовательностей и ClustalW для множественного выравнивания. Отработаны команды управления процессами: `jobs`, `ps`, `top`, `kill`, `fg`, `bg`. Изучена многопоточная программа `bowtie2`. Освоен менеджер терминалов `tmux`: создание и закрытие вкладок, разделение экрана, сохранение сессии при разрыве соединения. Все 30 шагов второй части пройдены успешно.
